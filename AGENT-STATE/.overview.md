# ScamCity Agent State / L1

## 读取顺序

1. 先读 `AGENT-STATE://.abstract.md`，核对更新时间、Git HEAD 和产物 mtime/hash。
2. 再按任务读取下表相关 L2 文件；不要全量加载。
3. 任务收尾先写 `AGENT-STATE://memories/events.md`，再同步受影响的摘要/索引。

## 写入纪律

- 新事实按资源、事件、待验收/状态、坑、规程分类写入；长证据放 `docs/worklogs/`，这里只留链接。
- 未运行的命令、未重启的 Minecraft、未观察到的日志不得写成已验证。
- 不删除既有条目；有冲突时以磁盘现实为准，并在事件日志标注差异。
- 不写密钥、token、私网配置或真实用户数据。
